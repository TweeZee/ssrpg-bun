    Interface Foe

    foe — the foe the player is currently targeting.

    Remarks

    Call the namespace itself to read the foe's name, mirroring StoneScript, where foe is both a variable and a class. Every member resolves to null when no foe is targeted, so guard on the value rather than assuming a foe is present.

    Example

    const name = await ssrpg.foe();
    const distance = await ssrpg.foe.distance();
    if (distance !== null && distance < 8) ssrpg.activate("R");
