    Interface Draw

    draw — direct drawing on the game screen.

    Remarks

    Unlike CommandQueue.print, these are immediate calls rather than queued commands, so each one costs a round trip and takes effect straight away. They deliberately bypass the per-step cache, so calling Draw.Clear twice in one step really clears twice.
