    Interface Screen

    screen — the visible viewport, plus conversion between world and screen coordinates.

    Remarks

    Screen.Next, Screen.Previous and Screen.ResetOffset are immediate calls that bypass the per-step cache, so calling one twice in a step really scrolls twice.
