    Interface Loc

    loc — the location the player is currently in.

    Remarks

    Call the namespace itself to read the location's name, mirroring StoneScript, where loc is both a variable and a class.

    Loc.Leave and Loc.Pause are commands rather than reads, so they are queued and take effect at the end of the step.

    Example

    if (await ssrpg.loc.begin()) {
      // first frame of the location — reset per-run state here
    }
